# Rudra Beads: App-Building Spec (from www.rudrabeads.in, crawled 4 Nov 2026)

## 1. Overview
- **Website name:** Rudra Beads (https://www.rudrabeads.in/)
- **What it is:** A catalogue and enquiry website for a Rudraksha and spiritual-products seller. It sells Nepali and Indonesian Rudraksha beads, Rudraksha malas and bracelets, Karungali (ebony) malas and bracelets, Rudraksha fruit, Gauri Shankar Rudraksha, Hessonite (Gomed) gemstone, pendants and crystal/gemstone bracelets.

There is **no cart, checkout, payment gateway, login or wishlist**. Every product has the CTAs "Get Best Quote", "Request Callback", "Get Latest Price" and "Yes! I am interested", and each one opens an enquiry form.

## 4. Product Data Model
These are all the fields seen across products. The spec fields are free-form key/value pairs, and different products show different subsets.
- `name`, `category`, `image` (IndiaMART CDN 500x500, e.g. 5.imimg.com/data5/SELLER/...), `price` (₹), `price_unit` (Piece / Pack / Oz / Carat), `min_order_qty` + unit, `description` (free text, sometimes includes a "Key Benefits" section)
- Rudraksha specs: Number Of Mukhi / Mukhi / Bead Type, Origin (Nepal/Indonesia), Bead Size, Size, Certification (Lab Certified / Not Certified), Lab Name (IGL, IGI, In House Lab), Treatment (Dyed / Natural / Unheated), Usage (Pendant, Bracelet, Mala Making, Puja, Jaap, Wearing, Collection), Usage/Application, Spiritual Use (Japa, Astrology), Shape, Fitting Type (Loose Bead), Ruling Deity / Ruling God, Ruling Planet, Color, Material, Grade, Weight, Brand, Packaging Type
- Mala/Bracelet specs: No/Number Of Beads, Thread/String Material, Mala Length, Bracelet Size/Material/Style, Finish Type, Product Type, Religious Theme, Gender, Ideal For, Stone Type, Quality, Purpose
- Gemstone specs: Stone Shape, Stone Weight, Stone Treatment, Stone Grade, Stone Cut, Clarity
- **Not present on the site:** variants, SKU, stock/inventory, compare-at price, reviews per product, multiple images/gallery.
